## 스킴은 둘이다

**light · dark 두 스킴입니다** (surf-ui, 2026-10-03). 바탕은 무채색이고 색은 콘텐츠(포스터)에서 옵니다 —
파랑(`accent`)은 화면의 주 행동 하나에만 씁니다.

| 상황 | 스킴 |
| --- | --- |
| 아무 설정 없음 | 시스템 설정(`prefers-color-scheme`)을 따른다 |
| `<html data-theme="dark">` | dark 고정 |
| `<html data-theme="light">` | light 고정 |

서브트리 하나만 고정할 땐 `lightThemeVars` · `darkThemeVars` 를 컨테이너 `style` 로 넣습니다.

<Callout tone="warning">
색은 **닫힌 축**입니다. spacing · radius · fontSize · lineHeight · letterSpacing · fontWeight ·
fontFamily · breakpoints 는 소비자가 덮을 수 있지만, color · cover · paper 는 COLDSURF 고정값입니다.
덮으면 브랜드가 아닌 다른 것이 됩니다.
</Callout>

### 어디까지가 "읽는 글자" 인가

글자색은 네 단계입니다 — `text`(본문 · 제목) · `body`(긴 본문) · `muted`(보조) · `subtle`.

**읽는 글자의 하한선은 `muted` 입니다.**

| | light | dark |
| --- | --- | --- |
| `muted` — `surface` / `bg` 위 | 5.28:1 / 4.81:1 | 6.97:1 / 7.67:1 |
| `subtle` — `surface` / `bg` 위 | 2.42:1 / 2.31:1 | 3.33:1 / 3.40:1 |
| `onAccent` — `accent` 위 | 4.88:1 | 4.88:1 |

<Callout tone="warning">
  **`subtle` 로 읽는 글자를 찍지 않습니다.** WCAG AA 는 4.5:1 입니다(18.66px bold · 24px 이상만 3:1).
  `subtle` 은 *읽히지 않아도 되는 것* — 구분선 · placeholder · 비활성 — 에만 씁니다.
</Callout>

cover scale 처럼 어두운 색면 위에서는 대비가 반대로 성립하므로 그쪽은 예외입니다.

## palette — 원색층

위 semantic color 가 *역할*(`--text` · `--border`)을 말한다면, 여기는 **색 자체**에 이름을 줍니다.
CSS 변수는 `--cs-*` 로 나갑니다.

역할 이름이 안 붙는 자리가 있기 때문입니다 — 그라디언트 정지색, 잉크 밴드 안의 타일 바닥,
내비 글자처럼 "그 색이어서 그 색인" 자리입니다. 그런 자리를 `--surface` 로 부르면 거짓말이 되고,
리터럴로 쓰면 팔레트가 움직일 때 혼자 뒤처집니다.

<Callout type="warn">
**의미이름이 있는 자리에 원색을 쓰지 마세요.** 본문 글자는 `palette.deepNight` 이 아니라
`color.text` 입니다 — 둘은 지금 같은 값이지만 같은 뜻이 아니고, 역할이 움직일 때 갈립니다.
원색은 *역할 이름이 없는 자리*의 탈출구이지 의미층의 대체재가 아닙니다.
</Callout>

앞 10색이 Figma 팔레트 보드이고, 뒤는 보드 밖 파생색입니다.
semantic color 와 `ink` 는 전부 이 표에서 파생합니다 — hex 정본은 여기 하나입니다.

## paper — warm paper

Figma 시안의 라이트 고정 표면 바닥색입니다.

<Callout>
`paper.warm`(`#fafaf7`)은 브랜드 정본 paper(`#f2efe8` = `color.bg`)와 **다른 값 · 다른 이름**입니다.
통일 대상이 아니라 *구별* 대상입니다. 새 off-white 를 들일 땐 값을 재사용하기 전에 이름부터 짓습니다.
</Callout>
