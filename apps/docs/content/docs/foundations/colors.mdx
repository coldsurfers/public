## 면은 두 벌이다 — ink · light

기본은 **light** 입니다. 어느 요소든 `data-surface="ink"` 를 달면 그 안은 **ink** 값이 됩니다.
한 페이지 안에서 섞습니다 — 홈은 히어로가 ink, 아래 묶음이 light 입니다.
ink 안에서 다시 밝은 면을 열 땐 `data-surface="light"` 입니다. OS 다크모드와는 무관합니다.

```tsx
<section data-surface="ink">…히어로…</section>
<section>…아래 묶음 (light)…</section>
```

### 읽는 글자의 하한

글자색은 `textPrimary` · `textSecondary` · `textTertiary` 셋입니다. **읽는 글자의 하한은
`textSecondary`** 이고, `textTertiary` 는 플레이스홀더 · 비활성 — 읽히지 않아도 되는 것 — 에만 씁니다.
