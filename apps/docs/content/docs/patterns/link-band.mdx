키커색 틴트 면에 선을 두른 띠입니다(Figma `1028:431` · `1028:468`). 위에 키커를 얹거나(`kicker`), 왼쪽에 큰 숫자를 둡니다(`lead`). 오른쪽 행동 글자는 기본 `›` 입니다.

링크는 `asChild` 로 — 자식 링크의 글이 띠의 한 줄이 됩니다.
