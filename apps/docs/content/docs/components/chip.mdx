## `active` 의 시각 언어는 여기가 정본이다

선택된 칩은 **잉크 바탕 + 흰 글자**입니다(`selectedFill` · `selectedText`). 2026-09-28 부터 `accent` 파랑이
정본이었는데, 시안 v3(Figma 1455:250)가 파랑을 주 행동 하나에만 남기면서 2026-10-17 에 잉크로 돌아왔습니다.

## 필터 칩은 링크여야 한다

필터된 면이 색인되려면 크롤 가능한 `<a href>` 여야 합니다. 그래서 필터 맥락의 기본 사용법은
`asChild` 입니다.

```tsx
<Chip asChild active={picked === '오늘'}>
  <Link to="?when=today">오늘</Link>
</Chip>
```
