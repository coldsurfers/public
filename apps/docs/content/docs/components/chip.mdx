## `active` 의 시각 언어는 여기가 정본이다

선택된 칩은 **`accent` 바탕 + 흰 글자**입니다. 한때 반전(ink 바탕 + paper 글자)이 정본이었는데,
동네 스위처 시안이 `accent` 로 선택을 말해서 2026-09-28 에 정본을 옮겼습니다.

다중선택에서는 조심합니다 — 필터 칩이 여러 개 켜지면 파란 바탕이 화면을 채웁니다. 그렇게 보이면
칩 수를 줄이거나 다른 컨트롤을 고릅니다.

## 필터 칩은 링크여야 한다

필터된 면이 색인되려면 크롤 가능한 `<a href>` 여야 합니다. 그래서 필터 맥락의 기본 사용법은
`asChild` 입니다.

```tsx
<Chip asChild active={picked === '오늘'}>
  <Link to="?when=today">오늘</Link>
</Chip>
```
