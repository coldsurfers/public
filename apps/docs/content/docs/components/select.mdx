트리거(현재값 + caret) + 팝오버 메뉴입니다. controlled 이고 라우터·데이터에 의존하지 않습니다 —
소비처가 `value` / `onChange` 를 들고, 옵션 라벨만 넘깁니다.

팝오버 뼈대(바깥클릭 · Escape · 위치잡기 · maxHeight)는 [Popover](/docs/components/popover) 가
소유합니다.
