네이티브 `<input type="checkbox">` 를 시각적으로만 감춥니다. 접근성·키보드·폼 제출·
react-hook-form 은 전부 네이티브에 그대로 위임하고, 칠하는 것만 가져옵니다.

`ref` 는 내부 실제 `<input>` 을 노출합니다 — `{ focus, blur }` 만 노출하면 RHF 의
`defaultValues` 가 깨집니다.

라벨 텍스트 색은 강제하지 않고 **부모에서 상속**합니다. 라이트 폼이든 다크 밴드든 감싼 문맥을
따릅니다.
