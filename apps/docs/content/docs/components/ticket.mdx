치수 · 타이포 · 내용은 전부 소비처의 몫이고, 여기가 책임지는 건 **형태**(종이 · 천공선 ·
노치)뿐입니다.

천공선과 노치는 Ticket 이 그립니다 — 소비처가 빠뜨릴 수 없게. `stub` 이 없으면 티켓은 그냥
종이 한 장이 됩니다.

## `responsive` 가 기본인 이유

좁은 화면에서 세로 천공선을 유지하면 본문이 눌립니다. `responsive` 는 tablet 을 경계로
`row` 와 `stacked` 를 오갑니다.

## 지면색

노치가 파여 드러나는 색은 기본이 warm-paper 캔버스입니다. 다른 바닥에 앉힐 때만 `ticketGround`
를 `style` 로 덮습니다.
