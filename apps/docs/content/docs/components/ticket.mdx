치수 · 타이포 · 내용은 전부 소비처의 몫이고, 여기가 책임지는 건 **형태**(종이 · 천공선)뿐입니다.

천공선은 Ticket 이 그립니다 — 소비처가 빠뜨릴 수 없게. `stub` 이 없으면 티켓은 그냥
종이 한 장이 됩니다.

## `responsive` 가 기본인 이유

좁은 화면에서 세로 천공선을 유지하면 본문이 눌립니다. `responsive` 는 tablet 을 경계로
`row` 와 `stacked` 를 오갑니다.

## 종이

종이는 문으로 고릅니다. 소비처가 종이 색 · 모서리 · 그림자를 덮지 않습니다.

| 문 | 종이 |
| --- | --- |
| `Ticket` | 흰 종이 · 테두리 · 모서리 `md` |
| `Ticket.Raised` | 흰 종이 · 모서리 `2xl` · 그림자 `sm` — 한 장이 먼저 읽혀야 할 때 |
| `Ticket.Muted` | 회색 종이 · 테두리 없음 · 모서리 `xl` — 떠오른 종이 옆에서 물러설 때 |
