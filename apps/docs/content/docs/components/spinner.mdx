light 트랙 링 + `accent` 270° 아크가 돕니다. 무한스크롤 푸터가 홈입니다.

`label` 이 없으면 스피너만 그리고, 스크린리더에는 "불러오는 중" 을 줍니다.

[ThinkingDots](/docs/components/thinking-dots) 와 의미 어휘가 다릅니다 — 이쪽은 *네트워크가
도는 중*, 저쪽은 *상대가 답을 고르는 중*입니다.
