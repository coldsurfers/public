<Preview name="button-basic" />

variant 는 다섯입니다. `primary` 는 ink 필, `accent` 는 러스트 필(랜딩 히어로 CTA),
`outline` 은 흰 배경 + 테두리, `ghost` 는 무테 텍스트 액션, `danger` 는 statusDanger 필입니다.

<Callout type="warn">
**`danger` 는 색이 아니라 뜻으로 고릅니다.** 되돌릴 수 없는 액션 — 탈퇴 · 영구 삭제 — 의
자리입니다. 눈에 띄게 하려고 고르는 것이 아니라 *되돌릴 수 없음*을 말하려고 고릅니다.
그래서 주 액션인 `accent` 와 나란히 서지 않습니다. 한 화면에 둘이 같이 필요하다면 둘 중
하나는 주 액션이 아닙니다.
</Callout>

## 크기와 아이콘

<Preview name="button-sizes" />

<Callout>
**size 는 셋입니다 — 늘리지 않습니다.** 시안 컨트롤 높이는 다섯 종이지만 그대로 받으면
`size` 가 7종이 됩니다. 그건 추상화가 아니라 목록입니다. variant 를 늘리기 전에
*이 축이 이 컴포넌트의 것인가* 를 먼저 묻습니다.
</Callout>

## 라우팅 CTA 는 `asChild`

버튼처럼 보이지만 실제로는 이동이면 `<button>` 이 아니라 `<a>` 여야 합니다.
`asChild` 는 자기 엘리먼트 대신 자식에 스타일을 입힙니다.

```tsx
<Button variant="accent" size="cta" asChild>
  <Link to="/this-weekend">이번 주말 보기</Link>
</Button>
```
