variant 는 넷입니다. `primary` 는 ink 필, `accent` 는 러스트 필(랜딩 히어로 CTA),
`outline` 은 흰 배경 + 테두리, `ghost` 는 무테 텍스트 액션입니다.

## 크기와 아이콘

<Preview name="button-sizes" />

<Callout>
**size 는 셋입니다 — 늘리지 않습니다.** 시안 컨트롤 높이는 다섯 종이지만 그대로 받으면
`size` 가 7종이 됩니다. 그건 추상화가 아니라 목록입니다. variant 를 늘리기 전에
*이 축이 이 컴포넌트의 것인가* 를 먼저 묻습니다.
</Callout>

## 라우팅 CTA 는 `asChild`

버튼처럼 보이지만 실제로는 이동이면 `<button>` 이 아니라 `<a>` 여야 합니다.
`asChild` 는 자기 엘리먼트 대신 자식에 스타일을 입힙니다.

```tsx
<Button variant="accent" size="cta" asChild>
  <Link to="/this-weekend">이번 주말 보기</Link>
</Button>
```
