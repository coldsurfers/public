## Toast 와 갈리는 지점은 수명이다

토스트는 1.6초 뒤 사라지는 **액션 결과**고, Callout 은 조건이 유지되는 동안 지면에 서 있는
**상태**입니다. 둘을 한 축으로 묶지 않습니다.

## `role` 을 붙여주지 않는다

같은 상자가 스크린리더에 읽혀야 할 때(소셜 로그인 콜백 실패)와 읽히면 방해일 때(정적 안내)가
있는데, 그건 DS 가 알 수 없는 맥락입니다. `...rest` 로 통과만 시킵니다.

```tsx
<Callout tone="danger" role="alert">로그인에 실패했습니다</Callout>
```

## 앞 아이콘은 `icon`

`icon` 은 본문과 한 덩어리입니다. 본문이 두 줄로 넘어가도 아이콘은 첫 줄 옆에 서고, 액션과 따로
접히지 않습니다. 장식이라 스크린리더에서는 숨깁니다.

## `margin` 을 소유하지 않는다

상자가 앞뒤 무엇과 서는지는 지면이 압니다. 바깥 여백은 소비처가 줍니다.
